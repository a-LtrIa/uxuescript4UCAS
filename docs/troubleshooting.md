# 故障排查

先确认使用的是最新发行版。下面按实际现象排查；同一现象可能来自课程限制、页面适配或模型服务，提交反馈时请保留出错前后的日志。

## 课程打不开，或没有启动确认

- **课程列表无法打开课程**：若学习通页面提供“体验新版”入口，可先切换再进入课程。这里切换的是学习通页面版本，与客户端版本不同。[相关反馈](https://github.com/unraous/uxuescript/issues/4#issuecomment-6247137115)
- **已进入页面但没有确认框**：先点击具体章节或任务点，进入实际播放页面。当前自动启动识别 `mooc1.chaoxing.com/mycourse/`；`mooc2-ans` 页面按课程概览处理。若实际播放页仍不触发，请提供域名、路径与页面截图，不要仅凭“没有弹窗”判断注入失败。[相关反馈 #29](https://github.com/unraous/uxuescript/issues/29)
- **有确认框但不运行**：选择 Yes 才会启动。刷新课程页会结束当前脚本并重置仪表盘，需重新确认；手动播放视频不等于脚本已启动。

仅封面或课程名称缺失时，先返回课程列表再进入课程。浏览器独立脚本不向桌面仪表盘报告进度。

## 视频播放完仍不切换，或倍速后任务未完成

先将 **Course → Speed Lock（锁定倍速）** 留空，保存后刷新课程页，以原速重新尝试。部分课程有观看时长要求，视频播到结尾不等于平台已记录任务完成；提高倍速也不一定缩短解锁时间。已有用户确认关闭倍速后恢复正常。[反馈 #33](https://github.com/unraous/uxuescript/issues/33#issuecomment-5892786039)、[时长限制反馈](https://github.com/unraous/uxuescript/issues/4#issuecomment-6250914329)

检查页面上的任务点完成标记和下一章节是否解锁。视频或 PDF 动作结束后，脚本仍需等待任务点标记；若原速下也持续不完成，记录停住的任务类型和日志，不要只根据仪表盘百分比判断。

## 切到后台或最小化后暂停

先恢复窗口，再用 Alt+Tab 切到其他应用，保持客户端不最小化，对比是否继续播放。部分电脑有最小化后课程页面冻结的反馈，目前没有通用解决办法；切换应用与最小化不能视为同一种情况。[维护者说明](https://github.com/unraous/uxuescript/issues/4#issuecomment-6250424489)

仍暂停时，反馈是否仅最小化触发、普通切换是否正常，以及系统、客户端版本与相关日志。

## 卡在视频内弹出的互动题

视频内互动题与章节测验是两条处理流程。当前脚本会处理可识别的视频互动题，不依赖模型 API Key；反复更换模型密钥不能解决这类页面适配问题。

旧版曾有连续互动题处理不全的问题，已在 v2.2.0 改进。先更新后重试；若仍卡住，提供弹题截图、同一视频是否连续出现多题，以及日志中的互动题匹配、填答或提交错误。[反馈 #35](https://github.com/unraous/uxuescript/issues/35)

## 章节测验不答题，或模型请求失败

在 **Configuration → API** 测试当前服务，再根据错误排查：

| 现象 | 处理 |
| --- | --- |
| `429`、`rate-limited` | 服务端或上游限流，密钥有效也可能出现。程序已对 429 重试；持续失败可稍后再试，或切换有可用额度的模型/服务 |
| 额度不足、认证失败、模型不存在 | 核对当前选中的 Provider、模型、密钥与账户额度，按服务返回的具体错误处理 |
| 自定义接口失败 | 填完整的 Chat Completions 请求 URL，不能只填 `/v1` |
| Ollama 没有模型，或内置列表找不到需要的模型 | 当前界面不自动发现 Ollama 模型，内置模型列表也不可编辑；通过自定义 Provider 添加兼容接口及准确模型 ID |

[#24 的日志](https://github.com/unraous/uxuescript/issues/24#issuecomment-5739912959)明确记录过 OpenRouter 上游 429，不能据此断定密钥无效或脚本未启动。模型列表问题也见 [#20](https://github.com/unraous/uxuescript/issues/20)、[#32](https://github.com/unraous/uxuescript/issues/32)；具体配置见[智能答题](usage/ai.md)。

连接测试通过只说明测试请求成功，不保证课程题目提取与填答正常。答案已填入但等待确认时，检查是否开启 **Course → Review Answers（人工核验）**；选择 No 会等待 30 秒后再次询问，要停止脚本请刷新课程页。

## macOS 首次打开被阻止

应用使用临时签名，未经过 Apple 公证。确认安装包来自项目发布页后，可前往 **系统设置 → 隐私与安全性 → 仍要打开**，按提示确认。旧版提示“已损坏”时，先安装最新版。

## 获取日志与提交反馈

默认数据目录在系统数据目录的应用标识子目录下；Windows 通常为 `%APPDATA%\top.unraous.uxs`，配置是 `config.toml`，日志在 `logs/`。已保存的配置可指定其他路径。

需要更详细的宿主日志时，先正常退出客户端，将 `config.toml` 顶层的 `log_level` 改为 `"DEBUG"`，重启并复现。修改已有字段，不要将它放入其他配置节；排查后可恢复为 `"INFO"`。

反馈请包含：

- 客户端版本、操作系统；独立脚本则注明浏览器与脚本来源。
- 停住的阶段、任务类型、是否开启倍速或人工核验；后台问题注明最小化与普通切换的区别。
- 复现步骤、页面截图、相关域名与路径，以及同一次运行中出错前后的日志。页面差异无法仅靠日志确认时，补充对应页面信息。

分享前移除密钥、账号、课程个人信息及 URL 查询参数中的令牌；无需公开登录凭据。配置文件中的 API Key 是明文，不要直接上传整份配置。浏览器脚本的粘贴和启动操作见[独立脚本指南](backend-free.md)。
