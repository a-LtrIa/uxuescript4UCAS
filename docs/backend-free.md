# 独立脚本：在浏览器控制台运行

无需桌面端时，可将 [`core.js`](../src-tauri/src/scripts/core.js) 全部内容复制到学习通网页的浏览器控制台执行，无需配置 API Key。

该模式支持已实现的视频和 PDF 任务，包括可识别的视频内互动题；不提供依赖桌面后端的章节测验答题。遇到这类测验时会跳过该任务点，请检查平台实际完成状态。

默认开启视频静音、关闭倍速锁定，因此直接复制运行不会自动设置两倍速。

## 操作步骤

1. 登录学习通网页版，进入课程播放页面。

   ![学习通课程播放页面](assets/backend-free/1748434809500.jpg)

2. 按 F12 打开开发者工具，切换到 **Console（控制台）**。

   ![打开开发者工具](assets/backend-free/1748434330109.jpg)

3. 复制完整 `core.js` 并粘贴到控制台。截图中的旧文件名 `main.js` 应替换为当前的 `core.js`。

   ![将脚本粘贴到控制台](assets/backend-free/1748434420451.jpg)

4. 按 Enter 执行，再按页面提示确认启动。

   ![脚本启动后的提示](assets/backend-free/1748434648962.jpg)

## 停止与排障

- 确认框选择“取消”不会开始任务。运行中按 F5 刷新页面可停止脚本；重新运行需再次粘贴。
- 浏览器阻止粘贴时，按控制台提示允许粘贴，再复制脚本。
- 使用中文浏览器界面。课程页面结构或语言变化可能影响任务识别；不兼容时先更新脚本，再提供复现步骤和脱敏日志。
